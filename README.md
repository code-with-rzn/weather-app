# Weather App 🌤️

A responsive weather application built with HTML, CSS, and JavaScript.

## Features

- Search weather by city
- Celsius and Fahrenheit temperature
- Weather condition descriptions
- Loading animation
- City-not-found handling
- Weather-themed UI

## Technologies

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Git & GitHub

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Enter a city name.
4. Click **Search**.
